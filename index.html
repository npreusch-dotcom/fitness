# Loading a New 10-Week Strength Program Momentum does not connect to ChatGPT or store an API key. It uses a manual, private workflow: 1. Open **Train**. 2. Tap **Copy ChatGPT prompt**. 3. Paste the prompt into ChatGPT. 4. Copy the JSON response. 5. Return to Momentum and tap **Load program**. 6. Paste the JSON and load it. Momentum validates that the program contains exactly ten weeks. The prompt requests Monday, Wednesday, and Saturday strength sessions. Existing Tuesday and Thursday cardio sessions are automatically retained when those days are absent from the imported program. Loading a program replaces future workout programming. It does not delete completed workouts, weight, body-fat readings, meals, or habit history. The imported JSON is saved only in the browser with the rest of the local Momentum data. Include it in regular Momentum backups.
