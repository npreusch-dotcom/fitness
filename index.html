# Loading a New 10-Week Strength Program Momentum does not connect to ChatGPT or store an API key. It uses a manual workflow: 1. Open **Train**. 2. Tap **Copy ChatGPT prompt**. 3. Paste the prompt into ChatGPT. 4. Copy the JSON response. 5. Return to Momentum and tap **Load program**. 6. Paste the JSON and load it. The 3.1 prompt asks ChatGPT to create Monday, Wednesday, and Saturday strength programming that works as independent micro-sessions across the day. It specifically avoids supersets, circuits, required sequencing, and uninterrupted timed workouts. Each exercise can be completed separately, one set at a time. Momentum validates that the program contains exactly ten weeks. Existing Tuesday and Thursday cardio programming is retained when those days are absent from the imported plan. Loading a program replaces future strength programming. It does not delete completed workouts, weight, body-fat readings, meals, protein entries, or habit history.
