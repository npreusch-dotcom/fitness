MOMENTUM COACH 3.0 - GITHUB UPDATE

1. Open the Momentum app currently on your iPhone.
2. In Coach > App and plan settings, create a backup first.
3. Open the SAME GitHub repository currently hosting Momentum.
4. Choose Add file > Upload files.
5. Upload EVERYTHING in this folder, including the icons folder and .nojekyll.
6. Replace the existing files and commit the changes.
7. Wait for GitHub Pages to finish deploying.
8. Open your GitHub Pages address in Safari with ?v=300 at the end once.
9. Fully close the Home Screen app and reopen it.

Keep index.html at the repository root. Do not upload the outer folder itself.
Your existing local entries use the same storage key and should migrate automatically.
